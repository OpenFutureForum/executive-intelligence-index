# Source concentration

The current eligible production source denominator is **0**.

| Measure | Value |
|---|---:|
| Eligible production sources | 0 |
| Largest publisher share | Undefined |
| OFF-owned source count | 0 |
| OFF-owned source share | Undefined |
| Vendor source share | Undefined |
| Source-type spread | 0 |

Shares are reported as undefined rather than 0%. A percentage with a zero denominator would be misleading. No source-concentration warning can be calculated, and absence of a warning does not establish diversity. Staging sources are excluded from these figures.

The principal concentration concern is therefore not dominance by a named publisher but the absence of an eligible production source base. The first production release should be checked for publisher, ownership, role, regional, language, and source-type concentration before it becomes the baseline for later comparisons.
