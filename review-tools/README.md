# Local review tools

`npm run generate:review-packets` indexes staged batch manifests for local review. The local interface opens a reviewer-selected JSON record in the browser and never uploads it. Generated packets and reviewer notes are not public build inputs.

Reviewers inspect the proposed and previous record, canonical source, exact locator, statement type, confidence, rights, duplicate and concentration warnings, AI-generated prose, and decision. Decisions enter canonical review records only after intentional contribution.
