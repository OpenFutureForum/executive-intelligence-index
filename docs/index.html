Three analytical layers

Source, proposition, synthesis

1. Source statements

What a named person or institution expressed, neutrally paraphrased and located precisely in a source.

2. Normalized propositions

3. Editorial synthesis

Boundaries

What this index does—and does not—claim

The current corpus documents selected public sources. It does not rank famous people, reproduce copyrighted transcripts, index private Forum Select conversations, or convert company claims into independently verified outcomes. OFF-owned sources and relationships are disclosed.

Current limitation: the framework is ready for controlled ingestion, but no unreviewed production research is used to make the site appear populated.
