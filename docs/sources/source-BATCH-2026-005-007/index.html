What the source reports or argues

  • The authors report a highest average attack success rate of 84.30% for a benchmark configuration.
  • Current defenses vary and often trade security against task performance.

Source-located statements

5 reviewed statements are indexed from this source.

  • ASB covers 10 scenarios and agents, 50 agent tasks, more than 400 tools, 400 attack tasks, 13 attack methods, 11 defenses, and seven metrics. (arXiv:2410.02644v4 PDF pp. 1-2 and p. 8, Abstract, Introduction, and Table 3)
  • Across the evaluated backbones, mixed attacks had the highest reported mean attack-success rate, 84.30%. (arXiv:2410.02644v4 PDF p. 9, Table 5, "Average" row and Section 5.3)
  • The authors identify attack surfaces in system prompts, user inputs, tool interactions, and long-term memory retrieval. (arXiv:2410.02644v4 PDF pp. 1-2, Abstract, Figure 1, and Introduction)
  • ASB defines net resilient performance as clean-task performance multiplied by one minus attack success rate. (arXiv:2410.02644v4 PDF p. 8, Table 4, NRP row)
  • The paper recommends choosing agent backbones using both task utility and adversarial resistance rather than capability rankings alone. (arXiv:2410.02644v4 PDF p. 9, Section 5.3, discussion following Figure 2)
