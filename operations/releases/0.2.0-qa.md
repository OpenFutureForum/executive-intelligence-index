## Accessibility review

The local browser inspection confirmed one `h1`, ordered heading levels, English document language, a single named main landmark, named primary navigation, a skip link targeting that main landmark, labelled collection search, header cells on data tables, and a readable non-graph relationship view. Measured contrast was 14.98:1 for primary body text and 8.08:1 for the primary button at a 1280×720 viewport, with no horizontal page overflow. Focus-reveal and reduced-motion rules are present in the stylesheet. A machine check is not a substitute for a named human accessibility review, screen-reader session, zoom review, or mobile-device inspection.
